# AwayStack

Frozen lick enrichment tower for dogs — a wind-up clock mechanism releases one cup at a time while you're out.

## About

AwayStack is a concept product page for an automatic dog treat dispenser. The site lets visitors browse product packs, choose add-ons, check delivery by PIN code, add items to a cart, and place an order with a branded invoice.

Built with Next.js 16 (App Router, static export), Tailwind v4, React 19, and Framer Motion.

## Installation

```bash
# Clone the repo
git clone https://github.com/ShivVk18/0905cs211163-hwa-hackathon.git
cd 0905cs211163-hwa-hackathon

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production (static export)
npm run build

# Preview the build
npm run start
```

The app runs on `http://localhost:3000`. The product page is at `/shop/awaystack`.
